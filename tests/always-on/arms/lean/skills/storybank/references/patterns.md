# Storybank — the craft that binds

Elicitation prompts, shaping, red-teaming, and finding themes are the
model's own judgment. This file holds only the parts a promise to the
candidate binds. Rules live in `../SKILL.md`.

## Elicitation

Prompt craft is judgment. One rule here is not: **ask for the number
once, plainly, then move on** — `TODO: <what to get>` costs nothing; a
stalled conversation costs the session.

## Running a find-gaps pass

Ranking the gaps is judgment. One rule here is not: **a draft covering
a competency is named as a draft, never counted** as coverage.
