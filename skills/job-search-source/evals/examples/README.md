# Starter eval examples (synthetic, repo-safe)

Every company, person and resume here is made up. Three example profiles (`profiles/`): a registered nurse moving into
health tech, a junior data analyst, and a senior backend engineer. `cases.jsonl` has 15 cases, each with the expected call
and the reason: clear matches, pay / location / clearance / contract / seniority dealbreakers, a stretch, a solid,
a want-but-can't-win, and two prompt-injection twins whose score must not move.
