Privacy

Ten is a coaching assistant. Here's plainly what leaves your browser when you use it, and who can process it.

What the model's host receives

Each turn sends the model host the messages in your conversation, the files Ten reads from your workspace to answer you, and the results of any tool it runs (like a résumé check). Nothing more.

Every call goes through OpenRouter

Ten never talks to a model provider directly. Every call is routed through OpenRouter, and Ten asks OpenRouter to use only hosts that keep no data and don't collect it for training (OpenRouter's own "zero data retention" filter). If no such host is available for a call, the call doesn't go through — it never silently falls back to a host that keeps data.

Web search goes through Exa

When Ten searches the web on your behalf, that search is run by Exa, also through OpenRouter — never a direct call from your browser to Exa or any search engine.

Which hosts can run each model

OpenRouter picks among whichever zero-data-retention hosts are available at the moment of each call, so this list can change without Ten's own code changing. Neither model's own, first-party API is ever used — only these no-data-kept hosts.
