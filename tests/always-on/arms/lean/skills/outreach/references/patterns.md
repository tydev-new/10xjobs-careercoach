# Outreach — the craft that binds

Finding contacts, enrichment, warm intros, and message frameworks are
the model's own judgment. This file holds only the parts a promise to
the candidate binds. Rules live in `../SKILL.md`; the standard in
`eval.md`; the file shape in `schema.md`.

## Enrichment

Sourcing and hook selection are judgment calls. One thing here is not —
the **identity gate**: an artifact binds to a lead ONLY with an
identity link (it names the company/role, or its author URL matches the
lead's profile URL). No link → a miss, never a maybe. The same-name
hazard is how a message meant for one person reaches another.
