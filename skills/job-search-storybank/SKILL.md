# Job-search storybank

Workspace default: `<search-workspace>/`.

## Goal
A bank of **memorable, owned stories** that cover the competency map — evidence for pitches, resume bullets, and interviews. The product is the **tell** (what sticks after 24 hours), not a filled-in template.

## Skill vs native
Follow `operating-rules.md` when present. **Native leads the tell** (scar → owned turn → one number → disagreeable lesson; spine/depth; altitude). This skill owns coverage map, `stories/` + `storybank.md`, confirm-only, improve loop, drill retrieval, and no-invent guardrails. STAR is optional translation only. File every strong chat draft into `stories/` — don't leave SSOT only in conversation.

## Coverage map (minimum)
Leadership/org scale · Conflict · Real failure · Delivery/metrics turnaround · Customer/enterprise · Cross-functional influence · AI/agents or technical depth · Feedback given/received

## Capture (native craft — default)
1. Pick highest-priority uncovered competency.
2. Elicit **one question at a time**, aiming for scar / owned turn / one proof number / disagreeable lesson.
3. Write `stories/S###-<slug>.md` and index in `storybank.md`. Status `confirmed` only if told directly.
4. Propose any new resume fact to base-resume/claim rules — never auto-write.

### Large transformations
Prefer **spine (~60–90s) + depth pocket** (follow-ups only).

### Level check
After a solid draft, sanity-check altitude: EM (squad) vs Director (multi-team OS) vs VP (portfolio / trust clock). Elevate only with real facts.

## Improve
Score 1–5 on: specific scar, owned turn, defensible metrics, sticky lesson, right altitude. ≤3 → improve loop, max 2–3 rounds; two rounds with no movement → DECISION.

## STAR (optional translation)
Use STAR only when the candidate or interviewer wants that frame. Native tell first.

## Drill retrieval
With 6+ confirmed stories: rapid-fire "which story for this question?" Log to `practice-log.md`.

## Guardrails
Never invent metrics, timelines, titles, or stakeholders. Vague stays vague until they add detail.
