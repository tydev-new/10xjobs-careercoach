# Coach — the craft that binds

Groundwork sensing, ranking, the goal math, the briefing shape, and the
progress review are the model's own judgment. This file holds only the
parts a script enforces or a promise to the candidate binds. Rules live
in `../SKILL.md`; the standard in `eval.md`; file shapes in
`schema.md`; every send, submit, and money moment renders per
`gate-grammar.md`.

## The goal and the math

Judgment — the model's own read of the funnel and the calendar.

## The inbox sweep

Search since the last sweep's recorded date. A shared account (not a
dedicated job-search inbox) is searched by known company/ATS senders
only, and the coverage is reported as partial — never silently treated
as complete.

Map each event to its pipeline row by company (+ role when a company
has several). **0 or 2+ matches → show the candidate the matches and
ask** — the same loud-fail rule `update_job.py` itself enforces; never
guess which row.

### Calendar

Read-only, same boundary as the inbox — never write, accept, or
decline an event.

## Tone

**Encouragement cites evidence or stays silent.** "S004 is practically
this JD's responsibilities section" is encouragement; "you've got
this!" is filler. **Never manufacture urgency, optimism, or praise** —
the mirror is the product; sycophancy is this system's failure mode.
The rest of the register is the model's own judgment.
