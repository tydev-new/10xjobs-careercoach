# Datagrid Labs — Analytics Engineer
# Source: https://datagrid-labs.example/careers/analytics-engineer

About Datagrid: Datagrid Labs builds a data-transformation platform for
operations teams.

We're hiring an Analytics Engineer to own our internal warehouse models
and the analytics layer our product ships on.

What you'll do:
- Design and maintain dbt models over our Postgres/Snowflake warehouse
- Build tested, reviewed, version-controlled data pipelines
- Set up CI for data: schema tests, freshness checks, regression alerts
- Work with product engineers to expose modeled data in the app

What we're looking for:
- 4+ years working with production data pipelines
- Expert SQL and solid Python
- dbt (or equivalent modeling framework) in production
- Software-engineering practices applied to data work: code review,
  testing, CI
- Nice to have: LLM/agent experience for data tooling

Compensation: $150,000–$180,000 base. Remote (US).
