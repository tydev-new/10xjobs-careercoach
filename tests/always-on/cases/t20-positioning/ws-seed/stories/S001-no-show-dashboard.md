**Status:** confirmed

Clinics were overbooking to hedge no-shows. I built a Tableau dashboard predicting daily no-show risk; 3 clinic managers now use it every morning for scheduling.
## Full STAR
S: overbooking chaos. T: give schedulers something they'd trust. A: built it in Tableau over claims data, iterated with the managers weekly. R: daily use by 3 managers.
## Earned Secret
