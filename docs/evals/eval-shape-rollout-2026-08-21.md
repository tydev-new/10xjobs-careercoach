## What the day settled (the design findings)

1. **SKILL.md is goal + loop shape, never steps.** Apply grew to ten
   numbered steps by "a sentence per measured miss"; the skeleton held
   the same cases at a third the length. Spec rule 3 now says so, with
   the receipt.
2. **A measured moment rule stays in the loop however short the loop
   is.** Two rules moved to references failed in the next run and
   recovered the round they came back.
3. **The loop needs its read step.** Four conversions in a row had a
   standard or a record the loop never read; each was a review finding
   before it was a harness miss.
4. **Every persisting loop scores as a count and keeps a round record**
   — profile, positioning, apply, coach aligned; storybank and learn
   ordinal by decision; apply's answers and outreach's draft exempt by
   decision. The ceiling is mechanical everywhere it exists.
5. **When prose fails twenty trials, it is the design or the stratum,
   not the wording.** The proposal-table problem was a work record
   mistaken for a proposal; deliver-first + a short block + a script
   fixed what sixteen rephrasings could not.
6. **The link checker had a blind spot** (`§` inside backticks); widened,
   it found a dangling, mis-depthed cross-skill link the same minute.
