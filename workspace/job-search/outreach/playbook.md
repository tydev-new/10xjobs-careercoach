## What Ben’s posts say (core)

### Don’ts (make the email 99% less bad)
1. **≤ ~200 words** — no life story
2. **No fancy / buzzword language** — read aloud; sound human
3. **Always include one clear ask**
4. **Be specific** — real numbers, named products, named companies
5. **Not spammy / not dishonest** — ≤1–2 follow-ups; no fake “loved your LinkedIn post” if untrue; OK to say you found them via a raise

### Dos — format
Every note: **(1) Who you are (2) Why you’re reaching out (3) Why they should care** + one ask (“Worth a chat?” / “How?” / pointer).

### Who to email
- Prefer **CEO or true hiring manager**; if unsure → **CEO** (or **CTO** for technical seats at <~100 people)
- **Do not wait for a posted job** — interest + value is enough (for startup motion)
- Find email: verify an approved recipient address before send; possible tools include ContactOut / Nymeria / Clay. A guessed pattern `{first}@{company-domain}` is not a verified contact.
- Volume: **~10–30 companies** over time; one great email is not a system
- Follow up **once** (max twice); reply fast when they respond

### Stand out beyond resume (show, don’t tell)
15–30 min value drops: mini user research, competitor note, candidate list for their req, careers-page feedback, short Loom — then attach that to the ask. Human, personal line from real research (blog/post) beats AI-slop templates.

## Compare outreach approaches (not personal history)
| ATS-first approach | Next Play approach |
|---|---|
| Soft check-in after ATS apply (“submitted today… happy to screen”) | Founder/HM value + clear ask; job post optional |
| Recruiter-first or HM+recruiter pair | Founder/CTO first at startups; recruiter secondary |
| LinkedIn DM drafts dominant | **Email** preferred when findable; LI/Twitter OK as channels |
| Wave packs of Applied silent roles | Also **pre-apply / no-post** interest targets; volume 10–30 |
| Long-ish proof paragraphs | ≤200 words; 2 proof bullets max |

## Adapt to the current role and organization
- **Startup / small organization:** identify the true functional HM; a founder can be appropriate when no HM is clear. Select the relevant function, not a former candidate’s preferred role.
- **Large organization:** skip spray-to-CEO; use a named HM or relevant functional leader + optional TA — Ben’s essay is startup-scoped.
- **Proof bullets:** select only current-user-approved claim IDs relevant to this role. No former candidate’s employer, achievement or metric is supplied.
- **Show-value ideas (optional, role-specific):** a short role-aligned plan, peer research, a product walkthrough or a customer-embed playbook. Mention a funding/product hook only when verified and relevant.
- **Warm path still stronger:** use an approved mutual when available; cold outreach is an option when a warm path is unavailable.

## Template (placeholders only — draft, not permission)

```
Hi {First} — {one true hook: product used / raise / JD mandate / mutual}.

I'm {approved_name}. {approved current positioning}. {one approved proof relevant to their problem; cite the current user's claim privately}.

Reaching out because {specific role or mandate} at {Company} fits {one concrete reason they should care tied to their problem}.

Worth a 15-minute chat on {one question}?
```

Word count target: choose outreach_words in policy.yaml. Keep the note short; no resume dump or pipeline jargon. Public-source numeric suggestions above are attributed advice, not a standing user rule.

## Operating cadence (proposed)
1. Choose a batch size, target-selection criteria and time window with the current user; outreach_batch_size is unconfigured, and no former applications or targets are supplied.

3. Choose outreach_followup_days and outreach_max_followups with the user. Do not install a schedule or send follow-ups without authorization.
4. Log in `contacts/<company>.md` with channel + date
